# Security Policy

## Supported Versions

We actively maintain and provide security updates for the latest `main` branch of Mene Tools.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

---

## Reporting a Vulnerability

The security and privacy of our users are of utmost importance. If you discover a security vulnerability or potential privacy defect in **Mene Tools**, please report it responsibly.

### How to Report
- **Email**: Send vulnerability reports directly to [contact@mene.app](mailto:contact@mene.app).
- **Do NOT open a public GitHub issue** for undisclosed security vulnerabilities.

### What to Include
- Detailed description of the potential vulnerability.
- Steps to reproduce or proof-of-concept payload.
- Expected vs. actual behavior.

### Disclosure Timeline
- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will provide an estimated resolution timeline and keep you updated on progress.
- Once fixed, we will publish an advisory and credit your contribution if desired.
